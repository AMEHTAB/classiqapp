# ClassIQ App

A static learning platform landing page and course discovery experience for ClassIQ.

## Features
- Responsive homepage with hero, trusted brand section, and certification cards
- Course listing page
- Login and signup pages
- Mobile navigation drawer
- Subscribe form interaction

## Project Structure
- `index.html` — main landing page
- `course.html` — course catalog page
- `login.html` — login page
- `signup.html` — sign-up page
- `styles.css` — shared styling
- `course.css` — course page styles
- `script.js` — UI interactions

## Notes
This project is built with plain HTML, CSS, and JavaScript.
